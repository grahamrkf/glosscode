# Privacy policy

GlossCode is a G-code editor that runs on your own computer. This policy covers every copy of it: from the Microsoft Store, winget, the apt and dnf package repositories, the Releases page, and the portable archives.

## What GlossCode collects

Nothing. GlossCode has no accounts, no analytics, no crash reporting and no advertising, and it makes no network connections of its own.

## What stays on your computer

- The programs you open and save, where you choose to keep them.
- Its settings (`settings.json`: recent programs, default machines by file type, view options), your machine profiles and your subprogram library, in its settings folder. Help › Open settings folder shows where that is. A portable copy keeps them in `GlossCode-data` beside the program.
- The webview's own cache, in GlossCode's cache folder.

None of it is sent anywhere. Uninstalling GlossCode leaves the settings folder in place, so a later install finds your machines again; delete the folder to remove them. The Microsoft Store copy is the exception: Windows deletes its settings folder when it's uninstalled.

## Links

Links in Help › About (the website, release notes and issues on GitHub) open in your web browser. What GitHub collects then is covered by [GitHub's privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).

## Changes

If a future version changes any of this, this page will say so before that version is released. The history of this page is in the repository's commits.

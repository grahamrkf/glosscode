Download GlossCode

The desktop program for Windows and Linux, and the web app to run on your own server. You don't need to download anything for the web app on this site.

Looking up the newest release…

Windows Windows 10 or 11, 64-bit

  • Installer (…-windows-x64-setup.exe): run it. It installs for your own user account without administrator rights, adds GlossCode to the Start menu, and can open .nc files with GlossCode. Remove it in Settings › Apps.
  • Portable (…-windows-x64-portable.zip): unzip it anywhere, a USB drive for example, and run GlossCode.exe. Its settings stay in a GlossCode-data folder beside it.
  • The program isn't signed yet, so Windows may show "Windows protected your PC" the first time. Click More info, then Run anyway.
  • It uses the Microsoft Edge WebView2 Runtime, which comes with Windows 10 and 11.

Linux 64-bit, glibc 2.35 or newer (Ubuntu 22.04, Debian 12, Fedora 36 and later)

  • Debian, Ubuntu, Mint (.deb): 
    sudo apt install ./GlossCode-VERSION-linux-amd64.deb
  • Fedora (.rpm): 
    sudo dnf install ./GlossCode-VERSION-linux-x86_64.rpm
    On openSUSE use sudo zypper install with the same file.
  • Both packages install the GTK 3 and WebKitGTK libraries they need, and add GlossCode to the applications menu.
  • Portable (.tar.gz): unpack it and run glosscode in the folder. Its settings stay beside it. It needs GTK 3 and WebKitGTK 4.1 installed (on Debian or Ubuntu: sudo apt install libgtk-3-0 libwebkit2gtk-4.1-0).

Web app for your own server

The same web app as on this site, as plain files with no server code. Use it to keep GlossCode on a shop network or a computer without internet access.

  1. Unzip GlossCode-VERSION-web.zip into a folder your web server serves (Apache, nginx, IIS, Caddy and so on). Any folder or address works, for example https://server/glosscode/.
  2. Serve it over HTTPS. Browsers allow the file pickers and the offline copy only over HTTPS, or from localhost.
  3. Make sure .wasm files are sent as application/wasm and .webmanifest as application/manifest+json. Most servers already do.

To try it on one computer, run a small local server in the unzipped folder and open http://localhost:8000/:

python3 -m http.server 8000

Opening index.html straight from the folder (a file:// address) doesn't work: browsers don't run WebAssembly or offline copies from local files.

Also in each release

  • Example programs (…-examples.zip): sample programs for Haas, Fanuc and Okuma mills and lathes, and example subprogram library files.
  • SHA256SUMS.txt: checksums of every file. On Linux: sha256sum -c SHA256SUMS.txt --ignore-missing. On Windows, in PowerShell: Get-FileHash .\GlossCode-…-setup.exe, and compare with the line in the file.
  • Older versions and release notes are on the releases page.

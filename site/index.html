A G-code editor that reads each line back to you

GlossCode is a G-code editor for CNC mills, lathes and plasma tables. Above every line of code it shows a gloss: a short plain-English reading of what the line does. It also checks the program for mistakes, tracks the active modes, and simulates the toolpath.

Code with its gloss

Each line of code has its gloss above it in small grey text, and its N number in a column of its own. You edit the code as plain text, and the gloss follows as you type.

spindle.fwd set.rpm speed:6000
N40M03 G97 S6000
tlen.on toffset:01 movz:1.0 cool.on
N50G43 H01 Z1.0 M08
run.feed movx:2.5 movy:-0.75 feed:16.0
N60G01 X2.5 Y-.75 F16.

What it does

Problems panel

Checks the program as you type: canned cycles missing words, feeds with no F or the spindle off, missing decimal points, arcs that don't close, missing length offsets, and codes that mean something else on your control.

Toolpath and simulation

XY toolpath (XZ on a lathe) that follows subprogram calls. Playback stops at M00 and M01, can skip block delete lines, and works out the run time from the programmed feeds and speeds.

Active modes

Motion, units, plane, feed mode, spindle, coolant, tool and offsets for the selected line, and a timeline of Z by line (X on a lathe) in run order.

Subprograms

Calls expand inline or open in a pane beside the program. A subprogram library keeps reusable subprograms with named variables.

Insert menu

Canned cycles with a sketch and a box for each word, a hole pattern tool (grid or bolt circle), and a guide (F1) to how each cycle moves.

Convert to another control

Matches each code by meaning and checks the result by comparing toolpaths. Machine profiles hold your own machines' limits and options.

Controls

Checked against programming manuals: Haas (NGC, classic and 1995 controls, mills and lathes), Fanuc (0i-F, 0i-D and Series 0, plus Custom Macro B), Okuma OSP (P300M, P200L, E100L, U10L and OSP700L), Mitsubishi (M800/M80 and M700/M70), Fagor (8055, 8060/8065), and LinuxCNC, Tormach PathPilot, GRBL, Centroid CNC12, Mazak EIA/ISO, Hurco WinMax (ISNC) and Siemens SINUMERIK ISO mode. Heidenhain TNC 640 Klartext and Hypertherm Phoenix/EDGE plasma are first drafts, not yet verified.

What each control doesn't handle yet is listed in control status. Any other control gets generic Fanuc-style rules, which may not match what it does.

Check every program on the machine before you cut. GlossCode is new and hasn't been widely tested. It can miss real problems and flag code that's fine. Prove each program out on the machine itself: run it through the control's own graphics, then a dry run or single block with the feed override turned down.

The web app runs the same screen and the same C core as the desktop program (built as WebAssembly), so a file you save is written exactly as the program writes it: unchanged lines byte for byte, the file's own line endings, ; marks and encoding. Nothing you open leaves your computer.

Run the web app on your own server

Each release has a GlossCode-<version>-web.zip: the web app as plain files with no server code. Unzip it into any folder your web server serves. It needs HTTPS (or localhost) for the file pickers and the offline copy. To try it on your own computer:

cd GlossCode-__GC_VERSION__-web
python3 -m http.server 8000

Then open http://localhost:8000/. More on the download page.
